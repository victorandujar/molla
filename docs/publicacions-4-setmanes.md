## Què mirar cada diumenge

- Vercel → Analytics: visitants per `utm_source` (`whatsapp`, `instagram`, `google`, `qr`).
- `npm run orders:prod -- funnel --days=7`: de la visita a la reserva, per canal.
- `/gestio`: comandes, a domicili o recollida, municipis.

Deixa de fer el que no porti reserves i dobla el que sí.
